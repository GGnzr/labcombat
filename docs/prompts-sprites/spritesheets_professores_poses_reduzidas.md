# Sprite sheets dos professores — poses reduzidas (versão 5)

> **Como usar (Google Flow / Whisk):** anexe a **imagem do modelo do professor** como referência de sujeito/personagem (ingrediente "subject") antes de gerar, e cole o prompt no campo de texto. Todos os prompts têm um "REFERENCE IMAGE LOCK" que manda o gerador copiar fielmente a aparência do modelo (rosto, roupa, cores, proporções) em todos os quadros. Dicas para o Flow:
> - Gere como **imagem** (não vídeo), proporção **paisagem/16:9** ou quadrada grande, para caber as 2 linhas de poses.
> - Se o Flow encurtar ou ignorar partes do prompt longo, corte primeiro as frases repetitivas do bloco "Sheet layout" — nunca corte o STYLE LOCK, o REFERENCE IMAGE LOCK, o FRAME VARIATION RULE nem a descrição quadro a quadro das poses.
> - Se os personagens saírem inconsistentes entre quadros, regenere a folha inteira em vez de pedir correção parcial.

**Mudança da v5:** adicionada a regra global "FRAME VARIATION RULE" em todos os prompts, proibindo frames duplicados/copiados dentro de um grupo de pose (causa mais comum de frames idênticos no IDLE, WALK e ATTACK). O prompt negativo também ganhou termos contra frames repetidos, e IDLE/ATTACK receberam reforço de diferença visível entre quadros.

A pedido, a folha agora traz só 6 grupos de pose, com variação de quadros onde você pediu:

- **IDLE (Parado):** 2 quadros, um ciclo sutil de respiração (inspirando/expirando), não uma pose diferente.
- **WALK (Caminhando):** 4 quadros com a alternância das pernas descrita quadro a quadro, para não repetir a mesma perna à frente duas vezes.
- **ATTACK NORMAL (Ataque normal):** 3 quadros, preparação, golpe no meio do movimento e impacto total.
- **DEFENSE (Defesa):** 1 quadro, guarda levantada.
- **SPECIAL (Especial):** 3 quadros mostrando o golpe sendo lançado em sequência — carregando, liberando e o efeito em força total.
- **DOWN (Caído):** 1 quadro, deitado no chão.

Tirei RUN, READY, ATTACK 2/3/4, JUMP, FALL, HIT, STUN e GET UP da folha, como pedido.

## Prompt negativo (use em todos)

```
blurry, anti-aliasing, smooth gradients, vector art, cartoon, chibi, 3D render, realistic, photo, different outfit between frames, inconsistent character, different style between frames, frames or boxes around sprites, colored title, numbered labels, misspelled text, extra limbs, deformed hands, overlapping sprites, background scenery, identical duplicate frames within a pose group, copy-pasted sprites, the same drawing repeated, mirrored or traced copies of the same frame
```
